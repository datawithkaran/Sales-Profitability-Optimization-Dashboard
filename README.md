Project Name:
Sales Profitability Optimization Dashboard

Tools Used:
• Excel
• SQL
• Power BI

Project Objective:
Analyze sales, profit, customer behavior, regional performance, and product profitability to identify business insights and profitability improvement opportunities.

Project Workflow:
1. Data Cleaning in Excel
2. SQL Analysis
3. Power BI Dashboard Creation
4. Business Insights & Recommendations

Dashboard Pages:
• Executive Summary
• Product Analysis
• Customer & Region Analysis

Key Features:
• KPI Cards
• Sales Trend Analysis
• Product Profitability Analysis
• Loss Making Products
• Customer Contribution Analysis
• Region-wise Performance
• Interactive Filters
• Business Insights

Business Insights:
• Technology category generated highest profit.
• Higher discounts negatively affected profitability.
• Some furniture products generated losses.
• West region contributed highest sales.
• Top customers contributed major revenue.
